RECOVERABILITY LEVELS (10 levels)
================================================================

Physical          -- the object physically exists
Structural        -- the material remains usable
Functional        -- the object is able to perform its function
Operational       -- the object can be used safely
Mission           -- the target mission is achievable
Component         -- the parts are useful even if the whole is not
Surrogate         -- via witness samples / emulations
Evidential        -- the object retains evidentiary value
Cultural          -- cultural / educational significance
Reconstructive    -- the function is recoverable through reconstruction

PROOF TESTING (3 levels, v2.2)
================================================================

Static Proof Test   -- the object exists, visually intact
Dynamic Proof Test  -- withstands pressure/load/cycles
Mission Proof Test  -- performs the target mission

Static proof != Dynamic proof != Mission proof

VIKING LESSON:
Periodic drill reactivation is mandatory.
Without it, a system loses its ability to return
imperceptibly, with no event, with no one to blame.

================================================================

Orphan Documentation =

Institutional Recovery Custodian =
a procedure activated when the custodians are lost

================================================================
TWO RISKS (from the Viking Case)
================================================================

RISK 1: Technology degradation
  The carrier becomes obsolete. The format is unreadable. The software will not run.
  A visible risk. Can be monitored and planned for.

RISK 2: Understanding degradation
  People leave. Documentation is lost.
  The knowledge of how to "read" it disappears along with the knowledge carriers.
  Less visible. More often left with no owner.

Both require separate safeguards.
