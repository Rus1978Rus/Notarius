8. INTERFACE_TO_RECOVERABILITY_GUARD_v0_1
- Derived from INTERFACE_THEORY_OF_PERCEPTION_IMPORT_v0_1A.
- Core rule: Interface State ≠ Recoverability State (verified recoverability).
- Formula: Apparent preservation ≠ proven recoverability.
- Examples: file opens ≠ semantic recoverability;
  object looks intact ≠ dynamic recoverability;
  archive exists ≠ custody chain alive;
  hash exists ≠ hash verified.
