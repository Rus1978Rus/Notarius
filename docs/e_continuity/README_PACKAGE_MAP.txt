1. WHAT THIS PACKAGE IS
====================================================================

This is a consolidated safety package of all documentation available in the current environment for the
E-Continuity / Managed Recoverability Framework project, including the old working name Template E.

The package was assembled on the following principle:
- take the physically found documents, ZIP, PDF, DOCX, Markdown, TXT and images;
- keep the current v2.3 master archive;
- keep the reviewer packages;
- keep legacy/old versions as fallback;
- add maps, manifest, provenance, checksums;
- add separate notes on rules, guards, patches,
  pending integrations and review/conveyor material.

Important:
This is NOT a new framework release.
It is a collection package / safety build.
The main substantive basis inside it: Template E v2.3 Full Master Archive RU.
Current project name: E-Continuity / Managed Recoverability Framework.
