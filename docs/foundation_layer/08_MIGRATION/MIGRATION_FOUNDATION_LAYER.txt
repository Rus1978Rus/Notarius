FO REVIEW METHOD
================================================================

Minimal entry filter (for new candidates):
1. Is there a concrete object or observation?
2. Can a formula be stated?
3. Does it not duplicate an existing FO?

Full review (before a status upgrade):
LEVEL_1: LLM review
LEVEL_2: CONCRETE_OBJECT_QUESTION_TEST
         (apply the FO to a pencil case — if it drifts into jargon → a signal)
LEVEL_3: CASE_LIBRARY (2 confirming + 1 boundary)
LEVEL_4: Conveyor run (4+ models)
